# DA-001 — Identidad visual

| Campo | Valor |
|---|---|
| Proyecto | Sistema de Planificación y Presupuesto de Compras para Navidad y Fin de Año |
| Identificador | DA-001 |
| Estado | Aprobada |
| Referencia visual | Programa 1 — Gastos_Familiares |

## 1. Decisión

Reutilizar la identidad visual del Programa 1, adaptando selectivamente sus componentes al nuevo sistema. No modificar el Programa 1.

## 2. Paleta de colores

| Token | Color | Uso |
|---|---|---|
| Azul profundo | `#172A46` | Navegación y elementos principales. |
| Verde | `#2E6B5B` | Acciones y estados positivos. |
| Dorado | `#D9C28F` | Acentos. |
| Fondo | `#F3F6FA` | Fondo general. |
| Superficie | `#FFFFFF` | Tarjetas y paneles. |
| Bordes | `#E5EAF0` | Separadores y contornos. |

## 3. Tipografía

Preferencia tipográfica: Inter, Segoe UI y Arial.

## 4. Componentes y estilo

- Tarjetas blancas.
- Bordes suaves.
- Sombras discretas.
- Esquinas redondeadas.
- Diseño responsive.
- Títulos y jerarquía visual consistentes.
- Formularios, tablas, gráficos, barras de progreso y alertas coherentes con el Programa 1.

## 5. Reutilización selectiva

Componentes candidatos:
- Sidebar.
- Topbar.
- StatCard.
- Tablas.
- Formularios.
- Gráficos.
- Barras de progreso.
- Alertas.

La adaptación debe evitar copiar CSS innecesario y no debe modificar archivos del Programa 1.

## 6. Fuente visual

Repositorio: https://github.com/ingjazar-jpg/Gastos_Familiares/tree/main

Tecnologías visuales identificadas en el Programa 1: React, Vite, JavaScript/JSX, CSS3 y Recharts.
